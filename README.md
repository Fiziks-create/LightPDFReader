# LightPDFReader

LightPDFReader is a Windows desktop PDF reader built with Python and PySide6.

## Features

- Standard PDF reading mode
- Interactive Book Mode with page flipping
- Page navigation and zoom controls
- PDF highlighting
- Dark brown interface
- GitHub release update checker

## Installation

Download `LightPDFReader_Setup.exe` from the [GitHub Releases](https://github.com/Fiziks-create/LightPDFReader/releases) page and run the installer.
